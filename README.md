# Hospital Performance Analysis

This project analyses synthetic hospital data to generate insights on patient behaviour, encounter patterns, cost trends, and readmissions.

### Key Areas
Patient demographics
Patient utilisation
Encounter analysis
Cost and coverage
Readmissions

### Tools Used
SQL (PostgreSQL)

Data analysis techniques (CTEs, window functions, sub-queries, aggregations)

### Key Insights
* Older patients account for a large share of healthcare demand.
* A small number of patients account for a high number of visits.
* Nearly half of encounters have no insurance coverage.
* Most encounters are of short duration (less than 24 hours).
* Readmission rates vary significantly depending on how they are measured, especially whether all follow-up visits or only inpatient cases are included.
